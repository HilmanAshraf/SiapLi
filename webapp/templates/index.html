Questions

Is my resume stored?+

No. The file is read once to extract text, then discarded. Only the anonymised skills are used for matching, and you can delete them anytime.

How do you decide "ready" vs "grow into it"?+

Ready means you have every skill a posting requires. Grow means you're missing one or two, and already have at least half — so it's realistically close.

Are the courses free?+

Yes. Every missing skill links to a free, reputable course with a rough time estimate.

Is this only for Malaysian students?+

It's tuned for Malaysian internship roles and the Year 2–3 timeline, but the method is general.

Method & resources

  • Skills extracted with a curated dictionary and word-boundary matching.
  • Matching compares your skills against each posting's requirements.
  • Readiness rule: all skills = ready; miss ≤2 with half = grow.
  • Personal data removed with pattern + name detection before analysis.
  • Course suggestions drawn from free, reputable providers.
  • Cohort dashboard aggregates anonymously; small groups are hidden.
